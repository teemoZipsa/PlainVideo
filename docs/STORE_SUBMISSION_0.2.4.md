# Microsoft Store Submission — PlainVideo 0.2.4

## Target

- Product ID: `9PDKQ88FKG1L`
- Identity: `SeonkyuIM.PlainVideo`
- Version: `0.2.4.0`
- Architecture: `x64`
- Device family: `Windows.Desktop`
- Minimum version: `10.0.17763.0`
- Distribution: free, no ads, no account, no telemetry

## Release scope

- Attach a supported subtitle by dropping it onto active playback.
- Remember and restore the last manually attached external subtitle per video.
- Register all 13 video extensions supported by the player shell.
- Use single-click left/right ten-second seeking with directional feedback,
  center play/pause, and center double-click fullscreen.
- Keep the release-approved, user-enabled 1080p 24→48 RIFE path with
  source-frame fallback.
- Keep experimental 30→60 and 4K compatibility disabled in the Store package.

## English Store release notes

Drop SMI, SRT, and other supported subtitles onto active playback and
PlainVideo will remember the last external subtitle for each video across app
restarts. Single-click the left or right video region to seek ten seconds with
directional feedback; use the center for play/pause and center double-click for
fullscreen. Windows associations and Explorer icons now cover WebM, MOV, AVI,
M4V, M2TS, MTS, TS, MPG, MPEG, WMV, and OGV in addition to MP4 and MKV. The
qualified optional 1080p 24→48 path remains available while experimental
30→60 and 4K paths stay disabled in the Store package.
