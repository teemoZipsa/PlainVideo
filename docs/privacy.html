Privacy

PlainVideo privacy policy

Effective date: July 21, 2026 · Reviewed: September 23, 2026

English한국어

PlainVideo plays files you choose on your Windows device. It has no account, advertising, analytics, telemetry, or tracking.

Files and settings

Media and subtitle files, playback, screenshots, preferences, window placement, and resume history are handled locally. PlainVideo does not upload file contents, names, paths, metadata, or viewing history.

Preferences and resume history are stored in the current Windows user profile. Uninstalling the app or clearing its local data may remove them.

Network and third parties

The current release has no network streaming, cloud sync, account, recommendations, crash reporting, or automatic telemetry. Source, support, and license links open in your browser only when you choose them.

PlainVideo includes open-source playback components. Their licenses and source information are included with the distributed package; see the third-party notices and source offer.

Questions and changes

For privacy questions, open an issue in the public PlainVideo repository. Do not include personal information in a public issue.

If data handling changes, this policy and the Microsoft Store listing will be updated before the changed version is published.

개인정보 처리 안내

PlainVideo는 사용자가 선택한 파일을 Windows 기기에서 재생합니다. 계정, 광고, 이용 통계, 자동 원격 진단, 추적 기능이 없습니다.

파일과 설정

영상·자막 파일, 재생, 화면 저장, 사용자 설정, 창 위치, 이어 보기 기록은 기기 안에서 처리됩니다. 파일 내용·이름·경로·메타데이터나 시청 기록을 서버로 전송하지 않습니다.

설정과 이어 보기 기록은 현재 Windows 사용자 프로필에 저장됩니다. 앱을 제거하거나 로컬 데이터를 지우면 이 정보가 삭제될 수 있습니다.

네트워크와 외부 구성요소

현재 배포 버전에는 네트워크 스트리밍, 클라우드 동기화, 계정, 추천, 충돌 보고, 자동 원격 분석 기능이 없습니다. 소스 코드·지원·라이선스 링크는 사용자가 선택했을 때에만 기본 브라우저에서 열립니다.

재생에 사용하는 오픈소스 구성요소의 라이선스와 소스 정보는 배포 패키지에 포함되어 있습니다. 외부 구성요소 고지와 소스 제공 안내도 확인할 수 있습니다.

문의와 정책 변경

개인정보 관련 문의는 PlainVideo 공개 이슈에 남겨 주세요. 공개 글에 개인정보를 적지 않도록 주의해 주세요.

데이터 처리 방식이 바뀌면 변경된 버전을 게시하기 전에 이 정책과 Microsoft Store 등록 정보를 업데이트합니다.
