Using PlainVideo

The Microsoft Store and portable builds are for x64 desktop devices running Windows 10 or 11.

English한국어

Everyday controls

Open a video
Drop a file onto the window or press Ctrl + O.
Play or pause
Click the center of the video or press Space.
Seek
Click the left or right side of the video to move 10 seconds, or use the arrow keys for 5 seconds. Hold Shift with an arrow key to move 30 seconds.
Fullscreen
Double-click the center or press F. Press Esc to return.
Volume
Use the Up/Down keys or mouse wheel. Press M to mute or restore sound.
Subtitles
Use the CC button or right-click menu. You can also drop one subtitle file onto a playing video.
Screenshot
Press S. PlainVideo saves the image in your Windows Pictures library.

PlainVideo looks for an external subtitle beside the video when their base names match. It remembers where you stopped in a partly watched file; use the right-click menu to restart from the beginning. Press Tab for media information.

Report a problem

Check existing reports or open a new issue. Include the PlainVideo and Windows versions, what you tried, and what happened. The media container and codec can help if you know them.

GitHub issues are public. Please leave out private videos, personal file paths, account details, and other sensitive information.

기본 사용법

영상 열기
파일을 창에 끌어다 놓거나 Ctrl + O를 누르세요.
재생·일시정지
영상 가운데를 클릭하거나 Space를 누르세요.
앞뒤 이동
영상 좌우를 클릭하면 10초, 방향키를 누르면 5초 이동합니다. Shift와 방향키를 함께 누르면 30초 이동합니다.
전체 화면
영상 가운데를 두 번 클릭하거나 F를 누르세요. Esc로 돌아옵니다.
음량
위·아래 방향키나 마우스 휠로 조절합니다. M으로 음소거를 전환합니다.
자막
CC 버튼이나 오른쪽 클릭 메뉴를 사용하세요. 재생 중인 영상에 자막 파일 하나를 끌어다 놓아 추가할 수도 있습니다.
화면 저장
S를 누르면 Windows 사진 라이브러리에 화면이 저장됩니다.

영상과 같은 폴더에 이름이 맞는 자막 파일이 있으면 자동으로 찾습니다. 보다 멈춘 영상은 이어서 재생할 수 있고, 처음부터 보려면 오른쪽 클릭 메뉴의 다시 시작을 사용하세요. Tab으로 미디어 정보를 볼 수 있습니다.
